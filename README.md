# Master Boards

An independent study desk mapped to the public MIT Sloan Master of Finance curriculum: five prerequisite sittings, nine core sittings, six quantitative engines, five tracks, and a board.

Each sitting opens with a film, then the lecture, the equations, and a drill. Progress stays in the browser.

This is not a degree, and it is not affiliated with MIT.

```bash
npm install
npm run dev
```

The desk runs at `http://127.0.0.1:8080`.
